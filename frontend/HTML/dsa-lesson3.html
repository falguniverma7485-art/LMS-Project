Lesson 03: Searching Algorithms

Learn how searching algorithms are used to find elements efficiently in a collection of data.

Lesson 03

What is Searching?

Searching is the process of finding a particular element or value from a collection of data. Searching is one of the most common operations performed while solving programming problems.

Why are Searching Algorithms Important?

Searching algorithms help us locate required information efficiently. The choice of searching technique depends on how the data is stored and whether the data is sorted.

Linear Search

Linear search checks each element one by one from the beginning of the collection until the required element is found or all elements have been checked.

Working of Linear Search

In linear search, the target element is compared with each element sequentially. If a matching element is found, its position can be returned. If no match is found, the search is considered unsuccessful.

Time Complexity of Linear Search

The time complexity of linear search is O(n) in the worst case because the algorithm may need to check every element in the collection.

Binary Search

Binary search is a more efficient searching technique that works on sorted data. It repeatedly divides the search range into two parts and determines which half may contain the required element.

Working of Binary Search

Binary search compares the target value with the middle element. If the target is smaller, the search continues in the left half. If it is larger, the search continues in the right half. This process continues until the element is found or the search range becomes empty.

Time Complexity of Binary Search

The time complexity of binary search is O(log n) because the search space is divided into half after every step. This makes it significantly faster than linear search for large sorted collections.

Linear Search vs Binary Search

Linear search can be used on both sorted and unsorted data, while binary search requires sorted data. Linear search checks elements sequentially, whereas binary search repeatedly divides the search space into smaller parts.

What You Will Learn

After completing this lesson, you should understand the purpose of searching algorithms and the basic working of linear search and binary search along with their time complexities.
