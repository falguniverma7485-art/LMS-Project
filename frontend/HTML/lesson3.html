Lesson 03: Introduction to CSS

Learn how CSS is used to style and design HTML webpages.

Lesson 03

What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the appearance and presentation of HTML elements on a webpage.

While HTML provides the structure of a webpage, CSS is used to make that structure visually attractive and easier to use.

Why Do We Need CSS?

Without CSS, webpages would mostly contain plain text and basic HTML elements. CSS allows us to control colors, fonts, spacing, borders, backgrounds and the overall layout of a page.

CSS also helps maintain a consistent design across multiple pages of a website.

HTML and CSS

HTML and CSS work together but have different purposes. HTML is responsible for the structure and content of a webpage, whereas CSS is responsible for its visual presentation.

CSS Syntax

A CSS rule generally contains a selector, a property and a value. The selector identifies the HTML element that we want to style.

The property describes what we want to change, while the value specifies how that property should appear.

CSS Selectors

Selectors are used to target HTML elements for styling. Common selectors include element selectors, class selectors and ID selectors.

CSS Properties and Values

CSS properties define the type of styling that should be applied. For example, color can change the text color, while font-size can change the size of the text.

Types of CSS

CSS can be added to an HTML document in three common ways: inline CSS, internal CSS and external CSS.

External CSS is commonly preferred for larger projects because the same stylesheet can be used across multiple HTML pages.

Basic CSS Example

For example, CSS can be used to change the color and size of a heading. By applying different CSS properties, we can create a clear and attractive design for a webpage.

What You Will Learn

After completing this lesson, you should understand the purpose of CSS, its basic syntax, selectors, properties, values and the different ways CSS can be added to HTML.
