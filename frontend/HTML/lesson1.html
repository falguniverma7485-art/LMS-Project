Lesson 01

Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create the structure of webpages.

What is HTML?

HTML is used to define the different parts of a webpage, such as headings, paragraphs, links, images, lists and more.

Basic HTML Structure

Every HTML document generally contains a doctype declaration, html element, head section and body section.

What You Will Learn

In this lesson, you will learn about HTML documents, headings, paragraphs and the basic structure of a webpage.
