Lesson 01: Introduction to Java

Learn the basics of Java and understand how Java programs work.

Lesson 01

What is Java?

Java is a popular, high-level programming language used to develop different types of software applications. It is widely used for web applications, desktop applications, mobile applications and many other software systems.

Features of Java

Java is known for being simple, object-oriented, secure, portable and platform independent. Java programs can run on different operating systems with the help of the Java Virtual Machine.

How Java Works

Java source code is written in a file with the .java extension. The Java compiler converts the source code into bytecode. This bytecode can then be executed by the Java Virtual Machine, commonly known as the JVM.

JVM, JRE and JDK

JVM stands for Java Virtual Machine and is responsible for executing Java bytecode. JRE provides the environment required to run Java applications, while JDK contains the tools needed to develop Java applications.

First Java Program

A basic Java program contains a class and a main method. The main method is the starting point from which a Java application begins execution.

Why Learn Java?

Learning Java helps develop strong programming fundamentals. It also provides a foundation for understanding object-oriented programming, data structures and application development.

What You Will Learn

After completing this lesson, you should understand what Java is, its major features, how Java programs are executed and the basic role of JVM, JRE and JDK.
