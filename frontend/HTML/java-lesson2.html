Lesson 02: Variables and Data Types

Learn how Java stores different types of data using variables and data types.

Lesson 02

What is a Variable?

A variable is a named memory location used to store data in a Java program. The value stored in a variable can be used and changed during program execution.

Declaring a Variable

Before using a variable, we generally specify its data type and give it a name. A variable can also be assigned an initial value at the time of declaration.

What are Data Types?

Data types specify what kind of value a variable can store. Java provides different data types for storing numbers, characters, decimal values and logical information.

Primitive Data Types

Java has eight primitive data types: byte, short, int, long, float, double, char and boolean.

For example, int is commonly used for whole numbers, double is used for decimal values, char stores a single character and boolean stores either true or false.

Non-Primitive Data Types

Non-primitive data types include types such as String, arrays and classes. They can be used to represent more complex data in Java programs.

Constants

A constant is a value that should not change after it has been assigned. In Java, the final keyword can be used when we want a variable to behave as a constant.

Type Conversion

Type conversion means changing a value from one data type to another. Java supports conversions between compatible data types.

Why Variables and Data Types are Important

Variables and data types are fundamental parts of programming. They allow a program to store, process and work with different kinds of information.

What You Will Learn

After completing this lesson, you should understand variables, primitive and non-primitive data types, constants and the basic idea of type conversion in Java.
