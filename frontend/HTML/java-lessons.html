Java Programming

Java Lessons

Learn Java programming from the basics.

Lesson 01

Introduction to Java

Java is a high-level, object-oriented programming language used to develop different types of applications.

What You Will Learn

You will learn about Java features, the basic structure of a Java program and how Java programs are executed.

Lesson 02

Variables and Data Types

Variables are used to store data in a Java program. Java provides different data types such as int, double, char and boolean.

What You Will Learn

You will learn how to declare variables, assign values and choose appropriate data types.

Lesson 03

Conditional Statements

Conditional statements are used to make decisions in a Java program based on different conditions.

What You Will Learn

You will learn about if, if-else and else-if statements in Java.

Lesson 04

Loops in Java

Loops allow us to execute a block of code repeatedly until a particular condition is satisfied.

What You Will Learn

You will learn about for loop, while loop and do-while loop in Java.
