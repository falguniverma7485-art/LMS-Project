Lesson 02: Arrays

Learn how arrays store multiple values and how common array operations are performed.

Lesson 02

What is an Array?

An array is a linear data structure used to store multiple values of the same type in a single variable. The elements of an array are stored in a specific order and can be accessed using their index.

Array Indexing

Array indexing starts from 0 in Java. This means the first element is stored at index 0, the second element at index 1, and so on. An element can be accessed directly using its index.

Declaring an Array

In Java, an array can be declared by specifying the data type followed by square brackets. Memory is then allocated for a fixed number of elements.

Traversing an Array

Traversal means visiting each element of an array one by one. A for loop is commonly used to traverse an array and perform an operation on every element.

Insertion in an Array

Insertion means adding a new element at a particular position. Since arrays have a fixed size, inserting an element may require shifting existing elements to create space.

Deletion from an Array

Deletion means removing an element from an array. After removing an element, the elements that come after it may need to be shifted so that the array remains organized.

Searching in an Array

Searching is the process of finding whether a particular element exists in an array. Linear search checks elements one by one, while binary search can be used on a sorted array for faster searching.

Updating an Array Element

An existing element of an array can be updated by accessing its index and assigning a new value. This operation is generally simple because arrays provide direct access using indexes.

Advantages of Arrays

Arrays provide fast access to elements using their indexes. They are simple to understand and are useful when the number of elements is known in advance.

Limitations of Arrays

One important limitation of arrays is their fixed size. Inserting or deleting elements from the middle of an array can also require shifting other elements.

What You Will Learn

After completing this lesson, you should understand arrays, indexing, traversal and common array operations such as searching, insertion, deletion and updating.
