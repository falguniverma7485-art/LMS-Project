Lesson 02: HTML Elements and Tags

Understand HTML tags and learn how different elements are used to build a webpage.

Lesson 02

What are HTML Tags?

HTML tags are special keywords written inside angle brackets. They tell the browser how different parts of a webpage should be structured and displayed.

Most HTML tags have an opening tag and a closing tag. The content is written between these two tags.

HTML Elements

An HTML element generally consists of an opening tag, some content and a closing tag. For example, a paragraph element is written using the paragraph tag.

HTML elements are the building blocks of a webpage. Different elements are combined to create the complete structure of a website.

Headings

HTML provides six levels of headings, from h1 to h6. The h1 heading represents the most important heading, while h6 represents a lower-level heading.

Paragraphs

The paragraph tag is used to display blocks of text. It helps organize written content into readable sections.

Links

Links are used to connect one webpage to another webpage or to another location on the same webpage. The anchor tag, represented by the letter a, is used to create links in HTML.

Images

Images can be added to a webpage using the image tag. Images make webpages more attractive and can also help explain information visually.

Lists

HTML provides ordered and unordered lists. Ordered lists display items with numbers, while unordered lists generally display items using bullet points.

Basic Example

A simple webpage can contain a heading, paragraph, link and other HTML elements. By combining these elements, we can create the basic structure of a webpage.

What You Will Learn

After completing this lesson, you should understand the purpose of HTML tags and elements and know how common elements such as headings, paragraphs, links, images and lists are used in a webpage.
