Web Development Lessons

Learn HTML and CSS step by step.

Lesson 01

Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create the basic structure of a webpage.

What You Will Learn

In this lesson, you will learn about HTML documents, headings, paragraphs and the basic structure of a webpage.

Lesson 02

HTML Elements and Tags

HTML elements are created using tags. Tags tell the browser how different parts of a webpage should be displayed.

What You Will Learn

You will learn about headings, paragraphs, links, images, lists and other commonly used HTML elements.

Lesson 03

Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to style and design HTML webpages.

What You Will Learn

You will learn about CSS selectors, properties, values and how CSS is connected with HTML.

Lesson 04

CSS Styling

CSS can be used to change colors, fonts, spacing, borders, backgrounds and the overall appearance of a webpage.

What You Will Learn

You will learn about colors, typography, margins, padding, borders and basic page styling.
